### 👨‍💻 About Me

**Backend Developer | AI/ML Engineer | Cloud & DevOps Enthusiast** with a strong interest in designing scalable backend systems, developing AI-powered applications, and building cloud-native infrastructure.

I enjoy solving complex engineering challenges by combining software development, machine learning, and modern DevOps practices to create reliable, secure, and high-performance solutions. My focus is on writing clean, maintainable code and delivering production-ready applications that provide real-world value.

**Areas of Focus**

- 🤖 **AI/ML Engineering** — Machine Learning, Deep Learning, MLOps, LLM Integration, Intelligent Automation
- ☁️ **Cloud & DevOps** — Docker, Kubernetes, CI/CD, Cloud Infrastructure, Monitoring & Automation
- ⚙️ **Software Engineering** — Clean Architecture, System Design, Scalable Applications, Security, and Best Practices

**Current Focus**
- Building scalable backend services and cloud-native applications
- Developing AI-driven solutions and MLOps pipelines

- Continuously expanding expertise in distributed systems, cloud technologies, and platform engineering
